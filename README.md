# Salary-prediction-using-simple-linear-regression
A machine learning project that predicts employee salaries using Simple Linear Regression in Python based on years of work experience

## Project Overview
This project uses Simple Linear Regression to predict employee salaries based on years of work experience. The model was built using Python and Scikit-learn and demonstrates data preprocessing, model training, prediction, and evaluation.

## Dataset
- Dataset: Salary_Data.csv
- Predictor: Years of Experience
- Target: Salary

## Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Results
- Positive relationship between years of experience and salary.
- Employees with more experience are predicted to earn higher salaries.
- MSE: 49,830,096.86
